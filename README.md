# Stereo Logic — RGB Audio Engine 🎧⚡

Stereo Logic is a futuristic mobile-first music player built as a Progressive Web App (PWA) with immersive RGB speaker visuals, real-time audio physics, offline support, and a premium cyber-dark UI.

Designed with an Apple × Rolls-Royce × Deep Space aesthetic.

---

## ✨ Features

- 🎵 Advanced Audio Playback
- 🌈 Reactive RGB Speaker Lighting
- 🎚️ 10-Band Parametric Equalizer
- 📱 Mobile-First Responsive UI
- ⚡ PWA Install Support
- 💾 Offline Caching with Service Worker
- 🔥 IndexedDB Playlist Persistence
- 🎧 Metadata & Album Art Detection
- 🔊 Stereo Channel Visualization
- 🚀 Smooth Physics-Based Animations
- 🌌 Premium Glassmorphism Interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- IndexedDB
- Service Workers
- PWA Manifest
